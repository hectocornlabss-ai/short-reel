# เทคนิคทั่วไปสำหรับตารางสตอรี่บอร์ด

เอกสารนี้เป็นเทคนิคอ้างอิงทั่วไปสำหรับการออกแบบตารางสตอรี่บอร์ด ใช้ได้กับทุกสถานการณ์ที่ Agent ต้องสร้างตารางสตอรี่บอร์ด

---

## หลักการแบ่งช็อต

**เริ่มช็อตใหม่เมื่อ**: เปลี่ยนฉาก/สถานที่, กระโดดเวลา, เปลี่ยนตัวละครหลักในภาพ, ขนาดช็อตเปลี่ยนชัดเจน, จุดหักเหของแอ็กชันสำคัญ

**ไม่ต้องเริ่มช็อตใหม่**: บทสนทนาต่อเนื่องในภาพเดียวกัน, สีหน้าเปลี่ยนเล็กน้อยหรือแอ็กชันเล็กๆ

ความละเอียด: 1 ภาพอิสระ = 1 ช็อต โดยประมาณทุก 50-100 คำของบทจะสอดคล้องกับ 1-2 ช็อต หากมีการบรรยายทรานซิชัน/เปลี่ยนฉากชัดเจน ให้แยกเป็นช็อตต่างหากด้วย

---

## กฎการรวมช็อตตั้งฉาก (ป้องกันความซ้ำซ้อน)

**ช็อตตั้งฉาก**: แต่ละฉาก/ตอนใหม่ ใช้ช็อตตั้งฉากได้สูงสุด 1-2 ช็อต ห้ามแบ่งเกิน 3 ชิ้นย่อย
- วิธีที่แนะนำ: 1 ช็อตไกลพร้อมการเคลื่อนกล้องเข้า (ตั้งฉาก+แนะนำตัวละครในช็อตเดียว) หรือ 1 ช็อตไกลมากตั้งฉาก + 1 ช็อตเต็มแนะนำตัวละคร
- วิธีที่ห้ามทำ: ถ่ายภาพสภาพแวดล้อมเปล่าก่อน → แล้วถ่ายรายละเอียดเฉพาะจุด → แล้วถ่ายตัวละครมาถึง (สามส่วนซ้ำซ้อน)

**ตรวจสอบการรวมช็อตด้วยตนเอง**:
- สิ่งที่จบได้ในช็อตเดียวอย่าแยกเป็นสองช็อต — ถ้าช็อตที่มีการเคลื่อนกล้องสามารถทำทั้งตั้งฉาก+แนะนำตัวได้พร้อมกัน อย่าแยก
- ช็อตที่บรรยายพื้นที่เดียวกันแต่ต่างจุด (ประตูสวน→เถาวัลย์→ห้องข้าง) ควรรวมเป็นช็อตเดียว ใช้คำบรรยายภาพครอบคลุมพื้นที่หลายชั้น
- ช็อตที่เป็นแค่การตกแต่ง (โชว์รายละเอียดสภาพแวดล้อมอย่างเดียว ไม่ขับเคลื่อนเนื้อเรื่อง) ควรรวมเข้ากับช็อตที่มีหน้าที่ทางเนื้อเรื่อง
- **ทดสอบแบบผู้กำกับ**: เขียนเสร็จแล้วตรวจสอบตัวเอง — ถ้าผู้กำกับตัวจริงจะรวม 2-3 ช็อตที่อยู่ติดกันเป็นช็อตเดียว แสดงว่าแบ่งละเอียดเกินไป ควรรวม

**กลยุทธ์ช็อตเดียวยาว (long take)**: เมื่อช็อตที่อยู่ติดกันมีการเปลี่ยนแอ็กชันต่อเนื่อง ฉากเปลี่ยนเล็กน้อย (เคลื่อนที่ในฉากเดียวกัน) หรือมุมกล้องค่อยๆ เปลี่ยน สามารถระบุ "ช็อตเดียวยาว" ใน `cameraMove` หรือ `description` เพื่อรวมช็อตย่อยหลายชิ้นเป็นช็อตต่อเนื่องยาวช็อตเดียว
- **ใช้ในสถานการณ์**: ตัวละครเดินผ่านพื้นที่, ติดตามแอ็กชันจากจุด A ไป B, วนรอบตัวละครเพื่อโชว์สภาพแวดล้อม, ตั้งฉากแล้วเคลื่อนเข้าไปถึงคลับอัพตัวละคร ฯลฯ
- **วิธีระบุ**: ใน `cameraMove` เขียนเส้นทางการเคลื่อนกล้อง (เช่น "ช็อตเดียวยาว: เคลื่อนเข้าช็อตไกล→ติดตามเข้าไปในสวน→จบด้วยช็อตเต็ม") ใน `description` บรรยายภาพจุดเริ่มต้นและจุดจบ
- **ผ่อนปรนความยาว**: ช็อตเดียวยาวเพราะมีข้อมูลอัปเดตต่อเนื่อง สามารถเกินเพดาน 6 วินาทีต่อช็อตได้ แต่ไม่เกิน 12 วินาที
- **คำเตือนความเสี่ยง**: ช็อตเดียวยาวเพิ่มความยากในการสุ่มสร้างภาพ (ต้องการความต่อเนื่องสูง) ใช้เฉพาะเมื่อประโยชน์ด้านความลื่นไหลของเนื้อเรื่องชัดเจนมากกว่าการตัดสั้นๆ อย่าใช้พร่ำเพรื่อ

**กฎ 6 วินาทีทองคำ**: ช็อตที่ไม่มีบทพูดถ้าผ่านไปเกิน 6 วินาทีแล้วยังไม่มีข้อมูลใหม่ (บทพูด/แอ็กชัน/ตัวละครเปลี่ยน) ความสนใจของผู้ชมจะขาดตอน ช็อตตั้งฉาก+ทรานซิชันต้องระวังเป็นพิเศษ ควรรวม/บีบอัดดีกว่าปล่อยให้ยืดเยื้อ

## กฎเหล็กความต่อเนื่องทางภาพ (ต้องยึดตลอดการออกแบบสตอรี่บอร์ด)

**① ความต่อเนื่องของแอ็กชัน**: ตำแหน่ง ความคืบหน้าแอ็กชัน และทิศทางของตัวละครระหว่างช็อตที่อยู่ติดกันต้องสอดคล้องตามหลักฟิสิกส์ ช็อตก่อนมือเหยียดไปกลางอากาศ → ช็อตถัดไปต้องต่อจากสถานะกลางอากาศนั้น ห้ามหดกลับกะทันหัน

**② กฎการไล่ระดับขนาดช็อต**: การเปลี่ยนขนาดช็อตต้องไล่ระดับแบบโฟกัสเข้าหรือคลายออก —
- โฟกัสเข้า: ไกล→เต็ม→กลาง→ใกล้→คลับอัพ (อารมณ์บีบเข้า)
- คลายออก: คลับอัพ→ใกล้→กลาง→ไกล (อารมณ์คลายออก)
- ห้ามใช้ขนาดช็อตเดียวกันต่อเนื่องโดยไม่มีเหตุผลทางเนื้อเรื่อง (ขนาดช็อตเดียวกันติดกันเกิน 3 ช็อต = ผู้ชมล้าสายตา)

**③ การรักษาแกนสายตา**: หลักการเส้น 180 องศา — ในฉากสนทนา/เผชิญหน้า ตำแหน่งซ้าย-ขวาของตัวละครในภาพต้องคงที่ตลอดฉาก ห้ามข้ามแกน

**④ ตรรกะเชิงพื้นที่ของทิศทาง**: คู่สนทนาหันหน้าเข้าหากัน, การใช้ของหันหน้าเข้าหาของ, มองไปไกลหันไปทางไกล ห้ามหันหน้าเข้ากล้องแบบไม่แยกแยะ

**⑤ การควบคุมข้อมูล**: แต่ละช็อตต้องตระหนักว่า "ตอนนี้ผู้ชมรู้อะไร ไม่รู้อะไร" —
- ให้เห็นมือแต่ไม่เห็นหน้า = ระทึกใจ; ได้ยินเสียงก่อนเห็นภาพ = ความคาดหวัง; เห็นแค่หลัง = ความห่างเหิน; เผยภาพเต็ม = จุดไคลแม็กซ์

**⑥ การควบคุมความหนาแน่นจังหวะ**: จำนวนแอ็กชัน/เหตุการณ์ในช็อตเดียวต้องสอดคล้องกับความยาว ป้องกันการยัดเนื้อหามากเกินไป —
- 1 แอ็กชันทางกาย = 1 จังหวะ, 1 การเคลื่อนกล้อง = 1 จังหวะ, 1 ประโยคบทพูดสั้น (≤10 คำ) = 1 จังหวะ
- ช็อต 2-3 วินาที: สูงสุด 1 จังหวะ; ช็อต 4-6 วินาที: สูงสุด 2 จังหวะ; ช็อต 7 วินาทีขึ้นไป: สูงสุด 3 จังหวะ

**⑦ โซนปลอดภัยหัว-ท้ายช็อต**: 0.5 วินาทีแรกและ 0.5 วินาทีสุดท้ายของแต่ละช็อตเป็นโซนเปลี่ยนผ่านที่ปลอดภัย ไม่วางแอ็กชันสำคัญหรือจุดเริ่มบทพูดตรงนี้ 0.5 วินาทีแรกใช้สร้างบรรยากาศหรือเปิดตัวนิ่งๆ 0.5 วินาทีสุดท้ายใช้ให้แอ็กชันจบลงอย่างเป็นธรรมชาติ

## แนวทางการกรอกฟิลด์

**description** (คำบรรยายภาพ): บรรยายเนื้อหาหลักของภาพในหนึ่งประโยค (15-50 คำ) ประกอบด้วย **ตัวละคร/สิ่งของหลัก + แอ็กชัน/สถานะ + พื้นที่สภาพแวดล้อม** ที่มองเห็นได้ ไม่เขียนความคิดในใจ ต้องแสดงชั้นความลึกของพื้นที่ (อย่างน้อยเกี่ยวข้อง 2 ชั้นจาก หน้า/กลาง/หลัง) เช่น "ม่านผ้าหน้าโบกไหว กลางภาพรถม้าตระกูลโหวมาถึงบ้านร้างลั่วเยี่ยนซาน", "เฉิงหม่าลงจากรถม้า มองดูสวนทรุดโทรม ภูเขาไกลๆ จมหายไปในแสงสนธยา"

> **🚫 ห้ามบรรยายแสง/โทนสี**: field description และทุกฟิลด์ **ห้าม**มีคำจำพวก `แสง`/`เงา`/`อุณหภูมิสี`/`โทนสี`/`โทนอุ่น`/`โทนเย็น`/`แสงย้อน`/`มืด-สว่าง`/`คอนทราสต์สูง` แสง/เงาทั้งหมดถูกกำหนดโดยอัตโนมัติจากภาพสินทรัพย์ฉากที่ช็อตนั้นอ้างอิง — ความต้องการแสงพิเศษ เช่น ฉากกลางคืน/ฝนตก/แสงไฟ ต้องแสดงผ่านการอ้างอิง**สินทรัพย์ฉากต่อยอด** (เวอร์ชันกลางคืน/เวอร์ชันฝนตก/เวอร์ชันแสงไฟ) เช่น ตัวอย่างข้อความต้นฉบับ "ภายใต้แสงยามเย็น" ก็ถือว่าผิดกฎ ควรลบออก

**shotSize** (ขนาดช็อต):

| ขนาดช็อต | คำอธิบาย | ความหมายเชิงเล่าเรื่อง |
|------|----------|---------|
| ไกลมาก (Extreme wide) | ภาพรวมสภาพแวดล้อมทั้งหมด | ตั้งฉาก / ความโดดเดี่ยว / ความเล็กจ้อย |
| ไกล (Wide) | ความสัมพันธ์ฉากกับตัวละคร | ความสัมพันธ์เชิงพื้นที่ / สร้างบรรยากาศ |
| เต็ม (Full) | ตัวละครเต็มตัวกับสภาพแวดล้อม | ตัวละครเข้าฉาก / โชว์ตัวเต็มตัว |
| กลาง (Medium) | ตั้งแต่หัวเข่าขึ้นไป | เล่าเรื่องประจำวัน / บทสนทนา |
| ใกล้ (Close) | ตั้งแต่หน้าอกขึ้นไป | สื่ออารมณ์ / จุดสำคัญของบทสนทนา |
| คลับอัพ (Close-up) | ใบหน้าหรือรายละเอียดเฉพาะจุด | เน้นอารมณ์ / อุปกรณ์สำคัญ |
| คลับอัพมาก (Extreme close-up) | รายละเอียดสุดขีด | อารมณ์ระเบิด / ช่วงเวลาชี้ขาด (ใช้อย่างระมัดระวัง ทั้งเรื่องใช้ได้ 2-3 ครั้ง) |

**cameraMove** (การเคลื่อนกล้อง): ไม่มีการเคลื่อนกล้องให้ใส่ `นิ่ง` การเคลื่อนกล้องต้องระบุทิศทางจุดเริ่ม-จุดจบ

| การเคลื่อนกล้อง | คำอธิบาย | ความหมายเชิงเล่าเรื่อง |
|------|----------|---------|
| ซูมเข้า | จากไกลไปใกล้ เน้นตัวละครหลัก | อารมณ์ทวีขึ้น / การค้นพบ / การแอบมอง |
| ซูมออก | จากใกล้ไปไกล โชว์สภาพแวดล้อม | อารมณ์ถอยห่าง / เผยภาพรวม / การจากลา |
| แพน | หมุนกวาดจากตำแหน่งคงที่ | อธิบายสภาพแวดล้อม / การค้นหา |
| เลื่อน | ติดตามตัวละครเคลื่อนที่ | การอยู่เคียงข้าง / การติดตาม |
| มุมสูงมองลง | จากบนลงล่าง | มุมมองคนนอก / ความเล็กจ้อย / ภาพรวม |
| มุมต่ำมองขึ้น | จากล่างขึ้นบน | ทำให้ดูยิ่งใหญ่ / ความกดดัน |

**action** (แอ็กชันตัวละคร): บรรยายแอ็กชันเฉพาะของตัวละคร/สิ่งที่เป็นตัวเอกในภาพ (5-40 คำ) ไม่มีแอ็กชันตัวละครให้ใส่ `ภาพเปล่า` รูปแบบคือ `(คำอธิบายการเชื่อมต่อ)คำบรรยายแอ็กชัน` ข้อกำหนด:
- **คำอธิบายการเชื่อมต่อวางไว้ต้นประโยค**: ใช้วงเล็บครอบ วางไว้หน้าสุด ช็อตแรกเขียน `(เริ่มเรื่อง)`; ช็อตอื่นเขียน `(ต่อจากช็อตก่อน:แอ็กชันเชื่อมต่อ)` เช่น `(ต่อจากช็อตก่อน:เคลื่อนกล้องเข้าจบที่ภาพหมู่นิ่ง)`, `(ต่อจากช็อตก่อน:แขนอยู่ในสถานะยกครึ่ง→ยกต่อขึ้น)`
- **วิธีเขียนสายแอ็กชัน**: เขียนสายแอ็กชันทางกายที่ต่อเนื่อง + จังหวะความเร็ว ("ค่อยๆ ยกมือขวาขึ้น→ปลายนิ้วสั่นเล็กน้อย→กำหมัดแน่นทันที") ห้ามเขียนแค่สถานะสุดท้ายแบบนิ่ง หลายตัวละครใช้ `;` คั่นแอ็กชันของแต่ละคน เรียงตามลำดับชื่อสินทรัพย์ที่เกี่ยวข้อง เช่น `หลี่อู้มือขวาลูบข้อมือเสื้อ→แขนซ้ายกอดตุ๊กตากระต่ายเข้าอก;เนี่ยเว่ยจ้องมองไปทางตุ๊กตากระต่ายไม่ละสายตา`
- **คอลัมน์นี้ไม่เขียนทิศทาง/ความสัมพันธ์เชิงพื้นที่อีก**: ทิศทางและความสัมพันธ์เชิงพื้นที่แยกเป็นคอลัมน์อิสระแล้ว (`orientation` / `spatialRelation`) ไม่ต้องระบุซ้ำใน action เพื่อป้องกันสัญลักษณ์ `|` ชนกับตัวคั่นคอลัมน์ตาราง markdown

**orientation** (ทิศทาง): คอลัมน์อิสระ ระบุทิศทางใบหน้าของตัวละครในภาพ รูปแบบ:
- หลายตัวละครเรียงตามลำดับ `associateAssetsNames` คั่นด้วย `;`: `ตัวละครA-3/4หน้าหันขวา;ตัวละครB-3/4หน้าหันซ้าย`
- ตัวละครเดียวสามารถละชื่อได้: `หันหน้าไปทางขวา`
- ภาพเปล่าและคลับอัพวัตถุล้วนให้ใส่ `—`
- ทิศทางต้องเป็นไปตามกฎแกนสายตา 180° (ล็อกไว้ตลอดฉากเดียวกัน หากต้องเปลี่ยนต้องมีแอ็กชันหันตัว/หันหน้าใน `action` และอัปเดตคอลัมน์นี้พร้อมกัน) ดูค่าที่ใช้ได้ในตารางอ้างอิงทิศทางด้านล่าง

**spatialRelation** (ความสัมพันธ์เชิงพื้นที่): คอลัมน์อิสระ ตำแหน่งสัมพัทธ์ของแต่ละตัวละครในภาพที่มีหลายตัวละคร รูปแบบ:
- เรียงตามลำดับ `associateAssetsNames` คั่นด้วย `、`: `ตัวละครA(ตำแหน่ง)、ตัวละครB(ตำแหน่ง)`
- ค่าตำแหน่งดูในตารางอ้างอิงความสัมพันธ์เชิงพื้นที่ด้านล่าง (9 ตำแหน่ง)
- ช็อตตัวละครเดียวใส่แค่ `ตัวละคร(ตำแหน่ง)` หรือใส่ `—`; คลับอัพวัตถุล้วน ภาพเปล่า ใส่ `—`
- ต้องสอดคล้องกับทิศทาง ขนาดช็อต การเคลื่อนกล้อง (ตัวละครที่หันขวา เป้าหมายที่มองควรอยู่ฝั่งขวาของเขา); ตัวละครกลุ่มเดียวกันในฉากเดียวกันต้องคงตำแหน่งมั่นคง การเปลี่ยนตำแหน่งต้องมีแอ็กชันเชื่อมต่อใน `action` และอัปเดตคอลัมน์นี้พร้อมกัน

**ตัวอย่างฟิลด์ครบ** (ภาพหมู่ 5 คน):
- `action`: `(เริ่มเรื่อง)ช็อตไกลค่อยๆ เคลื่อนกล้องเข้าหากลุ่มคน ทั้ง 5 คนยืนกระจายตัวหลวมๆ — หลี่อู้เอียงซ้ายเล็กน้อย แขนซ้ายกอดตุ๊กตากระต่าย;เนี่ยเว่ยสายตาถูกดึงดูดไปที่สีขาวก้อนนั้น`
- `orientation`: `หลี่อู้-3/4หน้าหันขวา;เนี่ยเว่ย-3/4หน้าหันซ้าย;เหอฉุนอวี่-3/4หน้าหันซ้าย;ชิวถง-3/4หน้าหันซ้าย;อันนา-หน้าตรง`
- `spatialRelation`: `หลี่อู้(ซ้ายหน้า)、อันนา(ขวาหน้า)、เนี่ยเว่ย(ซ้ายหลัง)、เหอฉุนอวี่(กลางหลัง)、ชิวถง(ขวาหลัง)`

**ตารางอ้างอิงทิศทาง** (ใช้กรอกคอลัมน์ orientation):

| ค่าทิศทาง | ความหมาย | ฉากที่ใช้ทั่วไป |
|---------|------|---------|
| หันหน้าไปทางขวา | หันหน้าแนวราบไปทางขวาของภาพ | ตัวละครฝั่งซ้ายของเส้น 180° เป้าหมายอยู่ฝั่งขวา |
| หันหน้าไปทางซ้าย | หันหน้าแนวราบไปทางซ้ายของภาพ | ตัวละครฝั่งขวาของเส้น 180° เป้าหมายอยู่ฝั่งซ้าย |
| หน้าตรง | หันตรงเข้ากล้อง | การพูดกับตัวเอง คำประกาศ มองตรงผู้ชม |
| 3/4หน้าหันขวา | 3/4 ด้านข้างเอียงขวาเข้ากล้อง | ตัวเอกบทสนทนา (ตัวละครฝั่งซ้ายของภาพ) |
| 3/4หน้าหันซ้าย | 3/4 ด้านข้างเอียงซ้ายเข้ากล้อง | ตัวเอกบทสนทนา (ตัวละครฝั่งขวาของภาพ) |
| ข้างหันขวา | เห็นเงาด้านข้างเต็มหันขวา | การพูดคนเดียว การครุ่นคิด |
| ข้างหันซ้าย | เห็นเงาด้านข้างเต็มหันซ้าย | การพูดคนเดียว การครุ่นคิด |
| 3/4หลังหันขวา | 3/4 ด้านหลังเอียงขวา | ความห่างเหิน การจากไป |
| 3/4หลังหันซ้าย | 3/4 ด้านหลังเอียงซ้าย | ความห่างเหิน การจากไป |
| หันหลัง | หันหลังให้กล้อง | การเข้าฉากแบบลึกลับ การจากลา การมองไปไกล |

> สามารถเพิ่มการก้ม/เงยได้: `หันหน้าไปทางขวาเงยเล็กน้อย`, `3/4หน้าหันซ้ายก้มเล็กน้อย`

**ตารางอ้างอิงความสัมพันธ์เชิงพื้นที่** (ใช้กรอกคอลัมน์ spatialRelation จำเป็นสำหรับฉากหลายตัวละคร):

แบ่งภาพเป็นตาราง 3×3 คอลัมน์ "ซ้าย/กลาง/ขวา" × ชั้น "หน้า/กลาง/หลัง" โดยหน้า=ใกล้กล้อง/ชั้นหน้า, หลัง=ไกลกล้อง/ชั้นหลัง; หน้า/หลังยังสื่อระดับสูง-ต่ำได้ (เช่น ผู้คุกเข่าถูกมองจากบนอยู่ตำแหน่ง "กลางหน้า" ผู้ยืนกดดันอยู่ "กลางหลัง")

| ค่าตำแหน่ง | ความหมาย | การใช้งานทั่วไป |
|---------|------|---------|
| ซ้ายหน้า | ฝั่งซ้ายของภาพ ใกล้กล้อง | ตัวเอกอยู่ซ้ายหน้า มักเป็นฝ่ายพูดนำ |
| กลางหน้า | กึ่งกลางภาพ ใกล้กล้อง | ตัวเอกเดี่ยวอยู่กลาง ถูกครึ่งตัวหน้าบัง |
| ขวาหน้า | ฝั่งขวาของภาพ ใกล้กล้อง | ตัวเอกอยู่ขวาหน้า |
| ซ้ายกลาง | ฝั่งซ้ายของภาพ ชั้นกลาง | ตำแหน่งซ้ายกลางในภาพหมู่ |
| กลางกลาง | กึ่งกลางภาพ ชั้นกลาง | ตัวเอกหลักอยู่กลาง ผู้นำบทสนทนา |
| ขวากลาง | ฝั่งขวาของภาพ ชั้นกลาง | ตำแหน่งขวากลางในภาพหมู่ |
| ซ้ายหลัง | ฝั่งซ้ายของภาพ ค่อนไปด้านหลัง (พื้นหลัง) | แถวหลังฝั่งซ้าย ผู้ติดตาม |
| กลางหลัง | กึ่งกลางภาพ ค่อนไปด้านหลัง | แถวหลังตรงกลาง ถูกด้านหน้าบังหรืออยู่ตำแหน่งสูง |
| ขวาหลัง | ฝั่งขวาของภาพ ค่อนไปด้านหลัง | แถวหลังฝั่งขวา ผู้สังเกตการณ์ |

**emotion** (อารมณ์): โทนอารมณ์ที่ภาพสื่อ (2-10 คำ) ใช้คำบรรยายที่เป็นรูปธรรมจับต้องได้ เช่น "เย็นชาดูถูก" "เจ็บปวดสิ้นหวัง" "ตึงเครียดกดดัน" ห้ามใช้คำกว้างๆ เช่น "มีความสุข" "เศร้า"

**scene**: ชื่อฉากที่ช็อตนี้อยู่ ต้องตรงกับฉากในบท

**associateAssetsNames**: รายชื่อสินทรัพย์ที่**มองเห็นได้**ในภาพ (รวมตัวละคร/สิ่งของที่ปรากฏเพียงบางส่วน) เพื่อให้ตรวจสอบเนื้อหาที่เกี่ยวข้องได้ง่าย

**duration**: อ้างอิงพื้นฐาน — คลับอัพ/สีหน้า 2-3 วิ · บทสนทนาใกล้ 3-5 วิ · เข้าฉากเต็มตัว 3-5 วิ · แอ็กชัน 2-4 วิ · ไกล/ภาพเปล่า/ทรานซิชัน 3-5 วิ · ฉากซับซ้อน 5-8 วิ **ช็อตเดียวไม่เกิน 8 วิ** เกินต้องแบ่ง

**เมื่อมีบทพูด ความยาวต้องพอสำหรับพูดบทพูดทั้งหมดและสอดคล้องกับความเร็วพูดตามอารมณ์**:

| สถานะอารมณ์ | ความเร็วพูดอ้างอิง | ตัวอย่างฉาก |
|---------|---------|----------|
| โกรธ เร่งรีบ ทะเลาะ | ~4 คำ/วินาที | ดุด่า เร่งเร้า ตกใจ |
| บทสนทนาปกติ การเล่าเรื่อง | ~3 คำ/วินาที | คุยกันประจำวัน พูดอย่างสงบ |
| เศร้า ลึกซึ้ง ครุ่นคิด | ~2 คำ/วินาที | สารภาพรัก ไว้อาลัย รำลึกความหลัง |
| กระซิบ อ่อนแรง ใกล้ตาย | ~2 คำ/วินาที | เสียงแผ่วเบา กระซิบข้างหู |

วิธีคำนวณ: จำนวนคำบทพูด ÷ ความเร็วพูดที่สอดคล้อง (ปัดขึ้น) = วินาทีพื้นฐาน แล้วบวกช่วงหยุดพัก:
- ทุกเครื่องหมายวรรคตอนในบทพูด (จุลภาค มหัพภาค จุดไข่ปลา ขีดกลาง) +0.3-0.5 วิ
- จุดเปลี่ยนอารมณ์/น้ำเสียง +0.5 วิ
- `duration` สุดท้าย = วินาทีพื้นฐาน + ผลรวมช่วงหยุด + สำรองความปลอดภัย 1 วิ (ปัดขึ้น)

**lines**: บทพูดต้นฉบับของตัวละคร **ต้องคัดลอกจากบทมาตรงตัวไม่เปลี่ยนแปลง** หลายตัวละครใช้รูปแบบ `ชื่อตัวละคร：บทพูด` เรียงกัน ไม่มีบทพูดใส่ `ไม่มีบทพูด` หนึ่งประโยคบทพูดต่อหนึ่งช็อต หลีกเลี่ยงการยัดบทสนทนาหลายตัวละครหลายรอบในช็อตเดียว

**sound** (เสียงประกอบ): บรรยายเสียงประกอบล้วนๆ แบ่งเป็นชั้น "เสียงบรรยากาศ + เสียงแอ็กชัน" เช่น "เสียงลมพัดไกลๆ + เสียงดาบกระทบ" ไม่มีเสียงใส่ `ไม่มีเสียงประกอบ`

> **🚫 ห้ามมีดนตรี/เพลงประกอบโดยเด็ดขาด**: ผลผลิตสุดท้ายของไปป์ไลน์นี้**ไม่มีเพลงประกอบเลย** คอลัมน์ `เสียงประกอบ` รับเฉพาะแหล่งเสียงจริง (เสียงบรรยากาศ + เสียงแอ็กชัน + เสียงเลียนแบบ) คำใดๆ เช่น "BGM" "เพลงประกอบ" "ทำนอง" "เครื่องดนตรีอย่างวงออร์เคสตรา/เปียโน/พิณ/ขลุ่ยใช้สร้างบรรยากาศ" **ถือว่าผิดกฎทั้งหมด** การตรวจสอบจะตัดสินว่าเป็นปัญหาร้ายแรง หากบทมีฉากเล่นดนตรีเป็นแอ็กชันในเนื้อเรื่อง (เช่น ตัวละครดีดพิณ) เขียนได้เฉพาะแหล่งเสียงทางกายภาพที่เป็นรูปธรรม เช่น "เสียงสั่นสะเทือนของโลหะจากปลายนิ้วดีดสาย + เสียงกังวานจากกล่องเสียง"

**associateAssetsIds**: ID ของสินทรัพย์ที่**มองเห็นได้**ในภาพ (ค่า `id` จริงจากข้อมูล assets) ห้ามสร้าง ID ที่ไม่มีอยู่จริง
- **ตัวละครปรากฏต้องอ้างอิง**: ตัวละครทั้งหมดที่ปรากฏในภาพ ไม่ว่าจะเป็นตัวเอกหรือเห็นแค่บางส่วน (เช่น ด้านหลัง มือ เงาเบลอ) ตราบใดที่ระบุได้ในภาพ ต้องอ้างอิง ID สินทรัพย์ที่ตรงกัน
- **ต้องมีสินทรัพย์ฉาก**: ทุกช็อตต้องอ้างอิง ID สินทรัพย์ฉากที่ตรงกับที่อยู่ (สินทรัพย์ type เป็น scene); หากฉากนั้นมีสินทรัพย์ฉากต่อยอดที่ตรงกับสถานะภาพปัจจุบัน ให้เลือกสินทรัพย์ฉากต่อยอด มิเช่นนั้นเลือกสินทรัพย์ฉากหลัก การขาด ID สินทรัพย์ฉากถือว่าฟิลด์ไม่สมบูรณ์
- กฎการเลือกสินทรัพย์แม่/ลูก: เลือก ID ตามสถานะที่ภาพในเนื้อเรื่องต้องการ — หากช็อตนั้นต้องการสถานะต่อยอดของสินทรัพย์หลัก **เลือกเฉพาะ ID สินทรัพย์ต่อยอด** เท่านั้น; เลือก ID สินทรัพย์หลักเฉพาะเมื่อไม่มีสถานะต่อยอดที่ตรงกัน ห้ามให้สินทรัพย์แม่และสินทรัพย์ต่อยอดของสินทรัพย์เดียวกันปรากฏพร้อมกันในสตอรี่บอร์ดเดียวกัน

## กฎการเปลี่ยนฉาก

- **ในฉากเดียวกัน**: ตัดฉับๆ (hard cut) เป็นค่าเริ่มต้นระหว่างช็อต
- **ข้ามฉาก**: แทรก 1 ช็อตภาพเปล่า (2-3 วิ) เพื่อบัฟเฟอร์อารมณ์ เนื้อหาภาพเปล่าต้องสอดคล้องกับบรรยากาศฉากก่อน-หลัง
- **ข้ามตอน**: สามารถระบุ "เฟดผสม (dissolve)" หรือ "เฟดเข้า-เฟดออก" ใน description ได้
- ห้ามใช้ทรานซิชันแบบแฟนซี (เลื่อนจอ หมุน ม่านบังตา ฯลฯ)
