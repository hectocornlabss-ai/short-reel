# 3D Guofeng Cyber Prop Image Generation - Constraint Manual
## (Full dual adaptation: Ancient-Style Xianxia + New-Chinese Urban Scenes)

---

## 1. Core Design Principles (Mandatory for Both Scenes)
1.  **Functional readability** — A prop's purpose must be obvious at a glance, with its form 100% serving its core function; classical functionality and cyber-functional visualization must be unified — energy ports, functional circuits, smart modules, and other cyber elements must directly convey the prop's purpose, with zero tolerance for meaningless elements
2.  **Extreme texture fidelity** — Materials must be rendered at 8K 3D precision, fully covering both **classical base materials** (metal/jade/wood/cloth/paper/porcelain/bronze) and **cyber-exclusive materials** (liquid metal/fiber optics/energy crystal/carbon fiber/holographic medium/microcrystalline glass), with complete PBR physical material properties
3.  **Dual-scene compatibility** — Every prop must be simultaneously suited to both "ancient-style xianxia scene adaptation" and "new-Chinese urban cyber scene adaptation," with Eastern classical form/new-Chinese design as the core skeleton and cyber functionality as a functional extension — pure Western cyber elements without a guofeng core are forbidden, and pure ancient-style/pure modern elements without cyber fusion are forbidden
4.  **Clear scale** — 3D modeling proportions must have zero distortion, accurately implying the prop's true size through structural proportion, optionally aided by standard reference objects to convey scale, suited to both the display proportions of ancient-style settings and the real-world usage proportions of urban daily life
5.  **Pure standalone prop display** — Only the prop itself may appear in the frame; any person, hand, or limb is strictly forbidden; the prop must not be held/worn/gripped/in use, and must be presented independently as a still-life display
6.  **3D production compliance** — All modeling must comply with next-gen 3D modeling standards: no clipping, no excessive triangle count, no perspective distortion, and must be directly usable in a full 3D modeling pipeline

## 6. Constraint Rules (Mandatory for Both Scenes + Strict Red Lines)
### Mandatory Rules (violation means non-compliant)
| No. | Mandatory rule |
|---|---|
| R1 | A "plain solid gray #B8B8B8 background" must be specified — no extraneous background elements, with a compliant scene-adapted background optional |
| R2 | The prop's material and craftsmanship must be clearly specified, with traditional and cyber materials clearly labeled, complete PBR properties, and a unified rendering standard |
| R3 | The prop's form must be anchored to Eastern classical form/new-Chinese design as its core skeleton — pure Western cyber/pure modern designs without a guofeng core are forbidden |
| R4 | Orthographic views must be used to present the four-panel multi-angle content, with precise 3D modeling proportions — no perspective distortion, clipping, or proportion imbalance |
| R5 | Dual-scene compatibility principles must be followed — every prop design must have adaptation room for both ancient-style and urban scenes; binding to a single scene is forbidden |
| R6 | All cyber-functional elements must serve the prop's core function and narrative — meaningless effect piling or element stacking is forbidden |
| R7 | The core rendering standard of 8K ultra HD, next-gen 3D rendering, and PBR physical materials must be followed, with no noise, aliasing, or blur |

### Strict Red Lines (any violation invalidates the result)
| No. | Strictly forbidden |
|---|---|
| X1 | Complex scene backgrounds, environmentally staged frames — any non-compliant, non-solid-color background element is forbidden |
| X2 | Props appearing in the same frame as a person — this manual is strictly for standalone prop reference sheets, so any person-related element is forbidden |
| X3 | Any appearance of a human figure, including full body, half body, or partial body (hand, finger, arm, or any limb) |
| X4 | The prop being held, gripped, worn, or in use — any pose implying a usage scenario is forbidden |
| X5 | Any element implying a person's presence (such as hand-holding marks, a wearer's viewpoint, a usage stance, or ergonomic gripping shapes) |
| X6 | Pure Western cyberpunk design without a guofeng core — any element out of place with the guofeng cyber worldview is forbidden |
| X7 | Overly futuristic, jarring elements in ancient-style scenes (such as urban smart hardware, firearms, or Western cyber symbols) |
| X8 | Jarring elements detached from the new-Chinese core in urban scenes (such as purely ancient cold weapons or illogical xianxia/fantasy elements) |
| X9 | Overexposed light effects — glow elements must be natural and soft, without disrupting the overall material texture and lighting balance |
| X10 | Any text, label, scale mark, watermark, logo, or other extraneous element appearing in the image |
| X11 | Distorted-perspective 3D modeling — the four-panel grid must use orthographic viewing angles, ensuring precise and unified prop structural proportions |
| X12 | Piling on cyber elements with no functional logic — every functional component must have a reasonable functional correspondence; ineffective design is forbidden |
