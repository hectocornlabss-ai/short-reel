# Prop Derivative State Generation · Constraint Manual

---

## 1. Derivative Principles

1. **Anchored design** — The prop's core design/silhouette must remain recognizable across all states
2. **Readable state** — State differences must be obvious at a glance so viewers can immediately distinguish them
3. **Serves the narrative** — Each state variant serves a specific story beat
4. **Progressive degradation** — Damage/aging states should follow sound physical logic
5. **Pure prop, standalone display** — Only the prop itself may appear in the frame; no person, hand, or limb of any kind is allowed. The prop must not be held/worn/gripped — it must be presented independently as a still-life display

---

## 2. State Types

### 2.1 Usage States

| State | Description | Applicable Props | Prompt |
|---|---|---|---|
| Brand new | Flawless, shining like new | All props | brand new, flawless, shining like new |
| Everyday use | Slight wear, natural patina | Weapons/objects/accessories | signs of everyday use, natural patina |
| Aged | Clearly weathered, dull color | Objects/tokens/scrolls | worn and weathered, aged, dull color |

### 2.2 Damage States

| State | Description | Applicable Props | Prompt |
|---|---|---|---|
| Slightly damaged | Small cracks/small chips/slight wear | Porcelain/jade pendant/weapons | fine cracks, slight chips |
| Broken | Visible cracks/fracture/shattering | Porcelain/accessories/weapons | visible cracks, shattered, broken |
| Fragment | Only a partial piece/fragment remains | Porcelain/jade pendant/tokens | fragment, broken piece, only half remains |

### 2.3 Special States

| State | Description | Applicable Props | Prompt |
|---|---|---|---|
| Blood-stained | Blood marks attached | Weapons/tokens/scrolls | mottled blood stains, blood-stained, anime rendering |
| Soaked/damp | Water marks, damp reflection | Scrolls/tokens/paper | soaked, damp paper, ink bleeding |
| Burned/scorched | Charred edges, fire marks | Scrolls/tokens/wooden items | charred edges, fire marks, carbonized |
| Glowing/activated | Inner energy, radiant glow | Tokens/magic items/jade | faintly glowing, inner radiance, cel-shaded glow effect |
| Wrapped/sealed | Wrapped in cloth or a box | Tokens/accessories/secret items | wrapped in brocade, sealed in a wooden box, guofeng packaging |

### 2.4 Environmental Adaptation States (New)

| State | Description | Applicable Props | Prompt |
|---|---|---|---|
| Snow-covered | Covered in snow | Weapons/objects/tokens | snow-covered, accumulated snow, wintry feel |
| Rain-soaked | Wet from rain | Paper/fabric/wooden items | rain-soaked, water marks, damp feel |
| Weathered by wind | Sand and wind erosion | Outdoor objects/weapons | wind-and-sand marks, wear, aged feel |
| Rusted | Metal oxidation | Weapons/metal accessories | rust spots, oxidation, sense of age |

## 3. State Variant Composition Specification

### Single-State Image

| Item | Constraint |
|---|---|
| Background | Plain moon-white color #E8EAF5 (consistent with the reference sheet) |
| Lighting | Even lighting, no hard shadows |
| Angle | Consistent with the front view in the original reference sheet |
| Proportion | The prop occupies 70%+ of the frame |

### State Comparison Image

| Item | Constraint |
|---|---|
| Layout | 2-3 states shown side by side in the same frame |
| Labeling | The state name is labeled beneath each state |
| Consistency | Angle/lighting/background fully consistent, only the state differs |

## 4. Material State-Change Rules

| Material | Brand New → Everyday Use | Everyday Use → Aged | Damage Manifestation |
|---|---|---|---|
| Metal | Bright sheen → slight patina | Patina → rust spots | Chips/nicked edge/fracture |
| Jade | Translucent and smooth → slight wear | Wear → faint surface cracks | Cracks/shattering/chipped corner |
| Wood | Fresh grain → natural patina | Patina → dull color | Splitting/fracture/worm damage |
| Porcelain | Glossy glaze → slight scratches | Scratches → dull glaze | Cracks/shattering/chips |
| Fabric/paper | Brand-new and smooth → slight creasing | Creasing → yellowed and brittle | Tearing/scorching/ink bleeding |

## 6. Constraint Rules

### Mandatory

| No. | Rule |
|---|---|
| R1 | The prop's core design/silhouette must remain recognizable across all states |
| R2 | State changes must follow sound physical logic |
| R3 | Must use a 2x2 grid layout: front + side + back + closeup |
| R4 | Must specify a "plain moon-white background", even soft light, no hard shadows |
| R5 | Must include the "guofeng anime + cel-shaded flat color" keywords |

### Strictly Prohibited

| No. | Prohibition |
|---|---|
| X1 | The prop becoming unrecognizable after a state change |
| X2 | Damage that violates physical logic (e.g. jade rusting) |
| X3 | Excessively gory/horrific damage depictions |
| X4 | Any human figure appearing, whether full body, partial body, or a body part (hand, finger, arm, etc.) |
| X5 | The prop being held, gripped, worn, or in use |
| X6 | Any element implying a person's presence (e.g. handling marks, a worn-from-POV angle, a usage pose) |
