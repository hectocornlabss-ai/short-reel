# รักหวานแหวว · ชุดเทคนิคการกำกับเชิงเล่าเรื่อง

## บทนำ

ชุดทักษะนี้เป็นชุดอ้างอิงเทคนิคการกำกับเชิงเล่าเรื่องแบบครบวงจรสำหรับเรื่องราวแนว **รักหวานแหวว** ครอบคลุมตั้งแต่การวางแผนเรื่องราวในภาพรวมไปจนถึงการปฏิบัติงานสตอรีบอร์ดในระดับรายละเอียด ใช้ได้กับทุกสไตล์ภาพ

## แนวคิดหลัก

- **สื่อสารอย่างเก็บงำ** — แสดงอารมณ์ผ่านช่องว่างและปฏิกิริยาที่ละเอียดอ่อน มากกว่าการใช้บทพูดอธิบาย
- **เล่นกับรายละเอียดเล็ก ๆ** — สัมผัสใจคนดูด้วยรายละเอียด เช่น สายตาหนึ่งครั้ง คำพูดที่กลืนกลับ ชายเสื้อที่ปลิวไหวตามลม
- **จังหวะดึงเข้า-ผลักออก** — เข้าใกล้ → ถอยห่าง → เข้าใกล้อีกครั้ง → เข้าใจผิด → พลัดพราก → กลับมาพบกัน แต่ละรอบต้องลึกซึ้งและหวานขึ้นกว่ารอบก่อน
- **พลังของความเงียบ** — ในช่วงอารมณ์สำคัญ ความเงียบทรงพลังกว่าเพลงประกอบ

## รายละเอียดไฟล์ทักษะ

### 1. เทคนิคการวางแผนเรื่องราว (`director_planning_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการวางแผนเรื่องราว** กำหนดแนวทางการวางแผนภาพรวมของแนวรักหวานแหวว ในด้านแก่นเรื่องและแก่นอารมณ์ จังหวะอารมณ์ การออกแบบอารมณ์ของฉาก และทิศทางเสียง

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| แก่นเรื่องและแก่นอารมณ์ | ความเก็บงำ ความหวานแบบพอดี เล่นกับรายละเอียดเล็ก ความอบอุ่นท่ามกลางความเย็นชา |
| โครงสร้างการเล่าเรื่องและการวางจังหวะ | พื้นฐานจังหวะช้า การไล่ระดับอารมณ์แบบค่อยเป็นค่อยไป โมเดลจังหวะดึงเข้า-ผลักออก |
| การออกแบบอารมณ์รายฉาก | การออกแบบฉากอารมณ์หลัก 6 แบบ การเล่าเรื่องผ่านระยะห่าง อุปมาเชิงพื้นที่ |
| ทิศทางเสียงและดนตรี | ความเงียบมาก่อน ดนตรีประกอบแบบแบ่งช่วง โมเดลการไล่ระดับอารมณ์ดนตรี |
| การจัดองค์ประกอบภาพและการเล่าเรื่องผ่านขนาดช็อต | องค์ประกอบแบบเว้นที่ว่าง / กรอบภาพ / กฎสามส่วน กลยุทธ์การไล่ระดับขนาดช็อต |
| การเคลื่อนกล้องและจังหวะ | นิ่งสงบสยบเคลื่อนไหว การแมปอารมณ์ของการซูมเข้า-ออกอย่างช้า ๆ การเคลื่อนกล้องแบบจังหวะหัวใจเต้น |

### 2. เทคนิคการเล่าเรื่องในตารางสตอรีบอร์ด (`director_storyboard_table_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการทำตารางสตอรีบอร์ด** กำหนดการไล่ระดับขนาดช็อต จังหวะการเคลื่อนกล้อง การควบคุมความยาว การรวมช็อต และตรรกะการเปลี่ยนฉาก ของแนวรักหวานแหวว ในตารางสตอรีบอร์ด

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| บทบาทของตารางสตอรีบอร์ด | คำอธิบายบทบาทของตารางสตอรีบอร์ดในฐานะเครื่องมือหลักของภาษาภาพ |
| การเลือกขนาดช็อต | การไล่ระดับขนาดช็อต คุณค่าของช็อตไกล ข้อจำกัดของโคลสอัพมาก การย่อช็อตสร้างฉากให้กระชับ |
| จังหวะการเคลื่อนกล้อง | นิ่งเป็นค่าเริ่มต้น ความหมายทางอารมณ์ของการซูมเข้า-ออกอย่างช้า ๆ การเคลื่อนกล้องแบบจังหวะหัวใจเต้น |
| การควบคุมความยาว | ความยาวอ้างอิงของช็อตแต่ละประเภท กฎทองคำ 6 วินาที |
| กลยุทธ์การรวมช็อต | ลดความรู้สึกว่าสร้างโดย AI ให้ความหนาแน่นของการเล่าเรื่องมาก่อน การตรวจสอบตนเองแบบนักกำกับ |
| ช็อตเดียวยาวต่อเนื่อง | เงื่อนไขที่เหมาะสมสำหรับช็อตยาว วิธีการระบุ ความยาวและความเสี่ยง |
| การออกแบบปฏิสัมพันธ์ตัวละคร | ข้อจำกัดการเคลื่อนไหวในช็อตเดียว ปฏิสัมพันธ์เชิงนัย |
| บทพูดและช่องว่าง | ความยาวมากเมื่อไม่มีบทพูด หนึ่งประโยคต่อหนึ่งช็อต การจัดการเสียงบรรยาย |
| การออกแบบการเปลี่ยนฉาก | ตัดตรง / ฉากว่างเปลี่ยนผ่าน / เฟดซ้อนภาพ |

## วิธีการใช้งาน

ชุดทักษะนี้ทำหน้าที่เป็นชุดอ้างอิงเทคนิคการเล่าเรื่องสำหรับ AI ผู้กำกับของ ToonFlow โดยจะถูกโหลดขึ้นมาโดยอัตโนมัติในกระบวนการสร้างเรื่องราว เพื่อชี้นำ:

1. **การวางแผนเรื่องราว** — กำหนดแก่นอารมณ์ เส้นโค้งจังหวะ อารมณ์ของฉาก และทิศทางดนตรี
2. **การสร้างตารางสตอรีบอร์ด** — สร้างขนาดช็อต การเคลื่อนกล้อง ความยาว และแผนการเปลี่ยนฉากที่เป็นรูปธรรม โดยอิงจากการวางแผนเรื่องราว

ไฟล์ทั้งสองแบ่งหน้าที่กันชัดเจนและต่อเนื่องเป็นลำดับขั้น ตั้งแต่ "ทำไมต้องถ่ายแบบนี้" ไปจนถึง "ถ่ายอย่างไรโดยละเอียด" ครบวงจรสมบูรณ์
