# เกมจิตวิทยา · ชุดเทคนิคการกำกับเชิงเล่าเรื่อง

## บทนำ

ชุดทักษะนี้มอบชุดเทคนิคการกำกับเชิงเล่าเรื่องที่ครบถ้วนสำหรับเรื่องราวแนว **เกมจิตวิทยา** ครอบคลุมตั้งแต่การวางแผนเล่าเรื่องระดับมหภาคไปจนถึงการปฏิบัติงานสตอรี่บอร์ดระดับจุลภาค ใช้ได้กับสไตล์ภาพทุกรูปแบบ

## แนวคิดหลัก

- **ผิวสงบแต่กระแสใต้น้ำเชี่ยวกราก** — เสน่ห์หลักของเกมจิตวิทยาคือ "สิ่งที่พูดออกมากับสิ่งที่คิดไม่เหมือนกัน" ทุกประโยคมีนัยแฝง ทุกรอยยิ้มอาจเป็นกับดัก
- **ข้อมูลคืออาวุธ** — ใครถือครองข้อมูลคนนั้นถือครองความได้เปรียบ แรงตึงเครียดในการเล่าเรื่องมาจากความไม่สมมาตรของข้อมูล การปิดบัง และการเปิดโปง
- **เกมหลายชั้น** — เกมจิตวิทยาระดับสูงสุดไม่ใช่ A หลอก B แต่เป็น "A รู้ว่า B กำลังหลอก B รู้ว่า A รู้ B รู้ว่า A รู้ว่า B รู้" เป็นโครงสร้างการรับรู้ซ้อนกันเป็นชั้นๆ
- **สีเทาของมนุษยชาติ** — ในการเล่าเรื่องเกมจิตวิทยาไม่มีคนดีคนเลวที่แน่นอน ทุกตัวละครมีตรรกะและเหตุผลของตัวเอง

## คำอธิบายไฟล์ทักษะ

### 1. เทคนิคการวางแผนเล่าเรื่อง (`director_planning_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการวางแผนเล่าเรื่อง** กำหนดแนวทางการวางแผนโดยรวมของแนวเกมจิตวิทยาในด้านแก่นเรื่องและธีม จังหวะอารมณ์ การออกแบบอารมณ์ในฉาก และทิศทางเสียง

| หัวข้อ | เนื้อหาโดยสรุป |
|---|---|
| แก่นเรื่องและแก่นอารมณ์ | ความไม่ตรงกันระหว่างภายนอกและภายใน อาวุธข้อมูล การรับรู้หลายชั้น สีเทาของมนุษยชาติ |
| โครงสร้างการเล่าเรื่องและการวางจังหวะ | การควบคุมข้อมูล การสลับมุมมอง การออกแบบการหักมุม การสะสมและปลดปล่อยแรงตึงเครียด |
| การออกแบบอารมณ์แต่ละฉาก | การออกแบบ 6 ช่วงตอนเกมตัวอย่าง บทสนทนาคือสมรภูมิ การรุกรับด้วยความเงียบ |
| ทิศทางเสียงและดนตรี | ดนตรีประกอบที่กดดัน พลังทำลายของความเงียบ เสียงบอกใบ้เชิงจิตวิทยา |
| การจัดองค์ประกอบภาพและการเล่าเรื่องด้วยขนาดภาพ | องค์ประกอบเผชิญหน้า ขนาดภาพแห่งอำนาจ การจับไมโครเอ็กซ์เพรสชัน เกมในพื้นที่ |
| การเคลื่อนกล้องและจังหวะ | การหยุดนิ่งเผชิญหน้า การซูมเข้าที่กดดัน การบอกใบ้ความไม่สมดุล จังหวะคือจิตวิทยา |

### 2. เทคนิคการเล่าเรื่องในตารางสตอรี่บอร์ด (`director_storyboard_table_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการทำสตอรี่บอร์ด** กำหนดการควบคุมเกมด้วยขนาดภาพ การสะท้อนจิตวิทยาผ่านการเคลื่อนกล้อง แรงตึงเครียดจากความยาวช็อต การรวมช็อต และตรรกะการเปลี่ยนฉากของแนวเกมจิตวิทยาในตารางสตอรี่บอร์ด

| หัวข้อ | เนื้อหาโดยสรุป |
|---|---|
| ตำแหน่งของตารางสตอรี่บอร์ด | คำอธิบายบทบาทของตารางสตอรี่บอร์ดในฐานะเครื่องมือหลักในการควบคุมจังหวะเกมจิตวิทยา |
| การเลือกขนาดภาพ | ขนาดภาพไมโครเอ็กซ์เพรสชัน ขนาดภาพเผชิญหน้า ขนาดภาพควบคุมข้อมูล |
| จังหวะการเคลื่อนกล้อง | การหยุดนิ่งเผชิญหน้า การซูมเข้าที่กดดัน การเลื่อนเบี่ยงความไม่สมดุล จังหวะเชิงจิตวิทยา |
| การควบคุมความยาวช็อต | ความยาวแรงตึงเครียดของบทสนทนา การรุกรับด้วยความเงียบ จังหวะการหักมุม |
| กลยุทธ์การรวมช็อต | ความต่อเนื่องของบทสนทนา การรวมช่วงตอนเกม ความหนาแน่นของการเล่าเรื่อง |
| ช็อตเดียวยาวต่อเนื่อง | ช็อตยาวการเผชิญหน้า การเปลี่ยนอำนาจในพื้นที่ การรุกรับเชิงจิตวิทยา |
