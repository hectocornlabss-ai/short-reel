# ออฟฟิศในเมือง · ชุดเทคนิคการกำกับเชิงเล่าเรื่อง

## บทนำ

ชุดทักษะนี้เป็นชุดอ้างอิงเทคนิคการกำกับเชิงเล่าเรื่องแบบครบวงจรสำหรับเรื่องราวแนว **ออฟฟิศในเมือง** ครอบคลุมตั้งแต่การวางแผนเรื่องราวในภาพรวมไปจนถึงการปฏิบัติงานสตอรีบอร์ดในระดับรายละเอียด ใช้ได้กับทุกสไตล์ภาพ

## แนวคิดหลัก

- **ความสมจริงคือพลัง** — อาวุธเด็ดของการเล่าเรื่องแนวออฟฟิศคือ "ความสมจริง" ให้คนดูเห็นตัวเองในตัวละคร
- **การต่อสู้ใต้น้ำ** — ผิวหน้าสุภาพ แต่เบื้องหลังคือการต่อสู้ ความขัดแย้งในที่ทำงานไม่ได้อยู่ที่หมัด แต่อยู่ที่อำนาจต่อรองและสายผลประโยชน์
- **ราคาของการเติบโต** — ทุกครั้งที่ก้าวขึ้นมีราคาต้องจ่าย (การประนีประนอม/การสูญเสีย/การสงสัยในตัวเอง) เส้นโค้งการเติบโตไม่ใช่เส้นตรงขึ้น แต่เป็นแบบเกลียวหมุน
- **แสงสว่างของคนตัวเล็ก** — สิ่งที่สัมผัสใจที่สุดไม่ใช่กลยุทธ์ของเจ้านายใหญ่ แต่คือแสงสว่างเล็ก ๆ ของคนธรรมดาที่ยังยึดมั่นในตัวเองท่ามกลางระบบ

## รายละเอียดไฟล์ทักษะ

### 1. เทคนิคการวางแผนเรื่องราว (`director_planning_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการวางแผนเรื่องราว** กำหนดแนวทางการวางแผนภาพรวมของแนวออฟฟิศในเมือง ในด้านแก่นเรื่องและแก่นเนื้อหาที่ทำงาน จังหวะการต่อสู้ต่อรอง การออกแบบความตึงเครียดของฉาก และทิศทางเสียง

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| แก่นเรื่องและแก่นเนื้อหาที่ทำงาน | รากฐานความสมจริง การต่อสู้ต่อรองเชิงอำนาจ ราคาของการเติบโต แสงสว่างของคนตัวเล็ก |
| โครงสร้างการเล่าเรื่องและจังหวะการต่อสู้ต่อรอง | ขับเคลื่อนด้วยสายผลประโยชน์ การสลับรุก-รับ ความไม่สมมาตรของข้อมูล ผลแพ้ชนะเป็นระยะ |
| การออกแบบความตึงเครียดรายฉาก | การออกแบบฉากออฟฟิศหลัก 6 แบบ อุปมาอำนาจเชิงพื้นที่ การเล่าเรื่องผ่านระยะห่างทางสังคม |
| ทิศทางเสียงและดนตรี | เสียงพื้นหลังของเมือง การต่อสู้ต่อรองด้วยความเงียบ ดนตรีประกอบแบบมีจังหวะ การเล่าเรื่องด้วยเสียงบรรยากาศ |
| การจัดองค์ประกอบภาพและการเล่าเรื่องผ่านขนาดช็อต | องค์ประกอบเชิงอำนาจ/องค์ประกอบเผชิญหน้า/องค์ประกอบโดดเดี่ยว การแสดงออกเชิงอำนาจผ่านขนาดช็อต |
| การเคลื่อนกล้องและจังหวะ | ถือกล้องแบบสารคดี กล้องนิ่งเยือกเย็น การผลักดันแบบกดดัน การเคลื่อนกล้องแบบมีจังหวะหายใจ |

### 2. เทคนิคการเล่าเรื่องในตารางสตอรีบอร์ด (`director_storyboard_table_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการทำตารางสตอรีบอร์ด** กำหนดกลยุทธ์ขนาดช็อต จังหวะการเคลื่อนกล้อง การควบคุมความยาว การออกแบบช็อตบทสนทนา และเทคนิคการเปลี่ยนฉาก ของแนวออฟฟิศในเมือง ในตารางสตอรีบอร์ด

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| บทบาทของตารางสตอรีบอร์ด | คำอธิบายบทบาทของตารางสตอรีบอร์ดในฐานะเครื่องมือหลักของความสัมพันธ์ตัวละครและความตึงเครียดเชิงอำนาจ |
| การเลือกขนาดช็อต | ขนาดช็อตเชิงอำนาจ ขนาดช็อตระยะห่างทางสังคม ขนาดช็อตความรู้สึกโดดเดี่ยว |
| จังหวะการเคลื่อนกล้อง | นิ่งเยือกเย็นเป็นหลัก ถือกล้องแบบสารคดี ซูมเข้าช้า ๆ แบบกดดัน |
| การควบคุมความยาว | จังหวะบทสนทนา ความยาวการต่อสู้ต่อรองด้วยความเงียบ มอนตาจจังหวะเร็ว |
| การออกแบบช็อตบทสนทนา | สลับมุมตามตำแหน่งอำนาจ องค์ประกอบความสัมพันธ์สามเส้า ภาษาภาพของนัยแฝง |
| ช่วงอยู่คนเดียว | ความจริงหลังเลิกงาน การล่มสลายคนเดียว การคิดทบทวนยามดึก |
| บทพูดและนัยแฝง | พูดมีนัยแฝง การรุก-รับด้วยความเงียบ การจัดการภาพสำหรับศัพท์เฉพาะในที่ทำงาน |
| การออกแบบการเปลี่ยนฉาก | มอนตาจเวลา/ความเปรียบต่างเชิงพื้นที่/จังหวะตัดตรง/การเวียนของชีวิตประจำวัน |

## วิธีการใช้งาน

ชุดทักษะนี้ทำหน้าที่เป็นชุดอ้างอิงเทคนิคการเล่าเรื่องสำหรับ AI ผู้กำกับของ ToonFlow โดยจะถูกโหลดขึ้นมาโดยอัตโนมัติในกระบวนการสร้างเรื่องราว เพื่อชี้นำ:

1. **การวางแผนเรื่องราว** — กำหนดแก่นเนื้อหาที่ทำงาน เส้นโค้งจังหวะการต่อสู้ต่อรอง ความสัมพันธ์เชิงอำนาจของฉาก และทิศทางเอฟเฟกต์เสียง
2. **การสร้างตารางสตอรีบอร์ด** — สร้างขนาดช็อต การเคลื่อนกล้อง ความยาว และแผนการเปลี่ยนฉากที่เป็นรูปธรรม โดยอิงจากการวางแผนเรื่องราว

ไฟล์ทั้งสองแบ่งหน้าที่กันชัดเจนและต่อเนื่องเป็นลำดับขั้น ตั้งแต่ "ทำไมต้องถ่ายแบบนี้" ไปจนถึง "ถ่ายอย่างไรโดยละเอียด" ครบวงจรสมบูรณ์
