# เซียนโบราณแฟนตาซี · ชุดเทคนิคการกำกับเชิงเล่าเรื่อง

## บทนำ

ชุดทักษะนี้เป็นชุดอ้างอิงเทคนิคการกำกับเชิงเล่าเรื่องแบบครบวงจรสำหรับเรื่องราวแนว **เซียนโบราณแฟนตาซี** ครอบคลุมตั้งแต่การวางแผนเรื่องราวในภาพรวมไปจนถึงการปฏิบัติงานสตอรีบอร์ดในระดับรายละเอียด ใช้ได้กับทุกสไตล์ภาพ

## แนวคิดหลัก

- **บรรยากาศเชิงกวีมาก่อน** — วิญญาณของการเล่าเรื่องแนวเซียนโบราณคือ "ความหมายอยู่นอกภาพ" ภูเขาหนึ่งลูก สายน้ำหนึ่งสาย เมฆหมอกหนึ่งม้วน ล้วนเป็นการแสดงออกทางอารมณ์
- **ฟ้าดินและมนุษย์เป็นหนึ่งเดียว** — อารมณ์ของตัวละครหลอมรวมเป็นหนึ่งเดียวกับปรากฏการณ์ธรรมชาติ: เศร้าแล้วลมพัด โกรธแล้วฟ้าร้อง ตรัสรู้แล้วแสงสวรรค์ปรากฏ
- **ชะตากรรมและการตัดสินใจ** — แรงตึงในการเล่าเรื่องมาจากการดึงรั้งระหว่าง "ลิขิตสวรรค์" กับ "การท้าทายโชคชะตา" ยิ่งชะตากรรมที่ขัดขืนไม่ได้ ยิ่งการต่อสู้ยิ่งสัมผัสใจ
- **ความว่างเปล่าคือมหาวิถี** — ธรรมที่ลึกที่สุด ความรักที่เข้มข้นที่สุด ล้วนไม่ต้องพูดออกมา — อาศัยเหล้าหนึ่งไห กระบี่หนึ่งเล่ม ความเงียบท่ามกลางหิมะ

## รายละเอียดไฟล์ทักษะ

### 1. เทคนิคการวางแผนเรื่องราว (`director_planning_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการวางแผนเรื่องราว** กำหนดแนวทางการวางแผนภาพรวมของแนวเซียนโบราณแฟนตาซี ในด้านแก่นเรื่องและแก่นเนื้อหาเซียน จังหวะชะตากรรม การออกแบบบรรยากาศของฉาก และทิศทางเสียง

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| แก่นเรื่องและแก่นเนื้อหาเซียน | วิถีสวรรค์กับใจมนุษย์ ชะตากรรมและการตัดสินใจ การบำเพ็ญเพียรอย่างโดดเดี่ยว ความรักยิ่งใหญ่และความรักเล็กน้อย |
| โครงสร้างการเล่าเรื่องและจังหวะชะตากรรม | ปมชะตากรรมที่วางไว้ล่วงหน้า กรรมสามภพ การไล่ระดับการตรัสรู้ เส้นโค้งมหันตภัย |
| การออกแบบบรรยากาศรายฉาก | การออกแบบฉากเซียนหลัก 6 แบบ การเล่าเรื่องผ่านความสอดคล้องฟ้ากับมนุษย์ อุปมาการบำเพ็ญเพียรเชิงพื้นที่ |
| ทิศทางเสียงและดนตรี | ดนตรีโบราณเว้นที่ว่าง เสียงธรรมชาติและความเงียบ การไล่ระดับอารมณ์ของเสียงสวดมนต์/ปี่ขลุ่ย |
| การจัดองค์ประกอบภาพและการเล่าเรื่องผ่านขนาดช็อต | ภาพเขียนทิวทัศน์แบบเขียนภาพ/เว้นที่ว่างด้วยเมฆหมอก/แดนเซียนที่มีความลึก การแสดงออกเชิงภูมิธรรมผ่านขนาดช็อต |
| การเคลื่อนกล้องและจังหวะ | การเคลื่อนกล้องแบบขี่ลม การแพนฟ้าดินอย่างช้า ๆ การนิ่งขณะทำสมาธิ การตัดเร็วเชิงจิตสำนึก |

### 2. เทคนิคการเล่าเรื่องในตารางสตอรีบอร์ด (`director_storyboard_table_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการทำตารางสตอรีบอร์ด** กำหนดกลยุทธ์ขนาดช็อต จังหวะการเคลื่อนกล้อง การควบคุมความยาว การออกแบบฉากต่อสู้เวทมนตร์เซียน และเทคนิคการเปลี่ยนฉาก ของแนวเซียนโบราณแฟนตาซี ในตารางสตอรีบอร์ด

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| บทบาทของตารางสตอรีบอร์ด | คำอธิบายบทบาทของตารางสตอรีบอร์ดในฐานะเครื่องมือหลักของการถ่ายทอดบรรยากาศเชิงกวี |
| การเลือกขนาดช็อต | คุณค่าของช็อตไกลแบบทิวทัศน์ ช็อตกลางแบบเขียนภาพ โคลสอัพที่มีความขลัง |
| จังหวะการเคลื่อนกล้อง | ติดตามแบบขี่ลม แพนช้า ๆ แบบล่องลอย นิ่งขณะทำสมาธิ ซูมเร็วด้วยพลังกระบี่ |
| การควบคุมความยาว | ความสุขุมของช็อตบรรยากาศเชิงกวี จังหวะปล่อย-รั้งของการต่อสู้ ความว่างเปล่าของการตรัสรู้ |
| การออกแบบฉากต่อสู้เวทมนตร์เซียน | เขียนภาพมาก่อน พลังและบรรยากาศสำคัญพอกัน การขานรับปรากฏการณ์ท้องฟ้า |
| การเล่าเรื่องความสัมพันธ์ตัวละคร | การสืบทอดอาจารย์-ศิษย์ พันธะคู่บำเพ็ญ การเผชิญหน้าคู่อาฆาต |
| บทพูดและช่องว่าง | สั้นแต่ลึก บทพูดเชิงกวี ความรู้สึกบำเพ็ญเพียรจากความเงียบยาว |
| การออกแบบการเปลี่ยนฉาก | การเปลี่ยนฉากด้วยเมฆหมอก/การจางแบบภาพวาดหมึก/การหมุนเวียนสี่ฤดู/การตัดเข้าฝัน |

## วิธีการใช้งาน

ชุดทักษะนี้ทำหน้าที่เป็นชุดอ้างอิงเทคนิคการเล่าเรื่องสำหรับ AI ผู้กำกับของ ToonFlow โดยจะถูกโหลดขึ้นมาโดยอัตโนมัติในกระบวนการสร้างเรื่องราว เพื่อชี้นำ:

1. **การวางแผนเรื่องราว** — กำหนดแก่นเนื้อหาเซียน เส้นโค้งจังหวะชะตากรรม บรรยากาศของฉาก และทิศทางดนตรี
2. **การสร้างตารางสตอรีบอร์ด** — สร้างขนาดช็อต การเคลื่อนกล้อง ความยาว และแผนการเปลี่ยนฉากที่เป็นรูปธรรม โดยอิงจากการวางแผนเรื่องราว

ไฟล์ทั้งสองแบ่งหน้าที่กันชัดเจนและต่อเนื่องเป็นลำดับขั้น ตั้งแต่ "ทำไมต้องถ่ายแบบนี้" ไปจนถึง "ถ่ายอย่างไรโดยละเอียด" ครบวงจรสมบูรณ์
