# ตลกขบขัน · ชุดเทคนิคการกำกับเชิงเล่าเรื่อง

## บทนำ

ชุดทักษะนี้มอบชุดเทคนิคการกำกับเชิงเล่าเรื่องแบบครบวงจรสำหรับเรื่องราวประเภท **ตลกขบขัน** ครอบคลุมการชี้แนะตลอดกระบวนการตั้งแต่การวางแผนเล่าเรื่องระดับมหภาคไปจนถึงการปฏิบัติงานสตอรี่บอร์ดระดับจุลภาค ใช้ได้กับสไตล์ภาพทุกรูปแบบ

## แนวคิดหลัก

- **การฝ่าฝืนความคาดหวัง** — แก่นแท้ของมุกตลกคือ "ผู้ชมคิดว่าจะเป็นแบบนี้ แต่กลับไม่เป็น" ยิ่งช่องว่างระหว่างความคาดหวังกับความจริงมากเท่าไร มุกก็ยิ่งแรงเท่านั้น
- **จังหวะคือความตลก** — มุกเดียวกัน จังหวะถูกต้องคือหัวเราะลั่น จังหวะผิดคือความเก้อเขิน จังหวะเวลาคือทุกสิ่ง
- **ตัวละครมาก่อนมุก** — ตลกขั้นสูงสุดไม่ใช่การเล่นมุกฉลาด แต่คือความไร้สาระที่เกิดขึ้นเองตามธรรมชาติจากการปะทะกันของบุคลิกตัวละคร
- **หัวเราะพร้อมน้ำตา** — ความตลกล้วนๆ ทำให้ผู้ชมเหนื่อยล้าได้ง่าย การฝังอารมณ์ที่แท้จริงไว้ในความไร้สาระ จะทำให้หัวเราะไปหัวเราะมาแล้วรู้สึกซาบซึ้งขึ้นมาทันที

## คำอธิบายไฟล์ทักษะ

### 1. เทคนิคการวางแผนเล่าเรื่อง (`director_planning_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการวางแผนเล่าเรื่อง** กำหนดแนวทางการวางแผนภาพรวมของแนวตลกขบขันในด้านแก่นเรื่องและหัวใจของความตลก จังหวะมุกตลก การออกแบบอารมณ์ขันของฉาก และทิศทางเสียง

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| แก่นเรื่องและหัวใจของความตลก | การฝ่าฝืนความคาดหวัง ความตลกจากการปะทะของตัวละคร ความไร้สาระและความจริง หัวเราะพร้อมน้ำตา |
| โครงสร้างเล่าเรื่องและจังหวะมุกตลก | วงจรปูพื้น→ปล่อยมุก กฎสามครั้ง ความไร้สาระที่ทวีขึ้นเรื่อยๆ จังหวะอารมณ์ |
| การออกแบบอารมณ์ขันแยกตามฉาก | การออกแบบฉากตลกทั่วไป 6 แบบ การเล่าเรื่องด้วยห่วงโซ่ความเข้าใจผิด การทวีความเก้อเขิน |
| ทิศทางเสียงและดนตรี | ดนตรีประกอบที่สร้างความขัดแย้ง ความตลกจากความเงียบ เอฟเฟกต์เสียงช่วยเสริมมุก ความเงียบฉับพลัน |
| การจัดองค์ประกอบภาพและขนาดช็อตในการเล่าเรื่อง | ช็อตปฏิกิริยา/ความตลกแบบภาพกว้าง/องค์ประกอบภาพผิดที่ผิดทาง จังหวะเวลาของขนาดช็อตในมุกตลก |
| การเคลื่อนกล้องและจังหวะ | การซูมเข้าเร็วเพื่อจับปฏิกิริยา นิ่งเทียบกับวุ่นวาย มุมมองผู้สังเกตการณ์ที่สงบ การสะบัดกล้องฉับพลัน |

### 2. เทคนิคการเล่าเรื่องในตารางสตอรี่บอร์ด (`director_storyboard_table_narrative.md`)

ชุดเทคนิคอ้างอิงที่ผู้กำกับใช้ใน **ขั้นตอนการทำตารางสตอรี่บอร์ด** กำหนดกลยุทธ์ขนาดช็อต จังหวะการเคลื่อนกล้อง การควบคุมความยาว การออกแบบช็อตมุกตลก และเทคนิคการเปลี่ยนฉาก สำหรับแนวตลกขบขันในตารางสตอรี่บอร์ด

| หัวข้อ | สรุปเนื้อหา |
|---|---|
| ตำแหน่งของตารางสตอรี่บอร์ด | คำอธิบายบทบาทของตารางสตอรี่บอร์ดในฐานะเครื่องมือหลักควบคุมจังหวะความตลก |
| การเลือกขนาดช็อต | ขนาดช็อตปฏิกิริยา ความไร้สาระแบบภาพกว้าง คลอสอัพที่ผิดที่ผิดทาง |
| จังหวะการเคลื่อนกล้อง | นิ่งสงบเทียบกับซูมเข้าเร็วเพื่อจับปฏิกิริยา มุกจากการสะบัดกล้อง การตามถ่ายความวุ่นวายที่ควบคุมไม่ได้ |
| การควบคุมความยาว | ความยาวช่วงปูพื้น จังหวะการปล่อยมุก มุกจากการเว้นช่องว่าง การกู้สถานการณ์เมื่อเงียบเหงา |
| การออกแบบช็อตมุกตลก | ภาษาภาพจากปูพื้น→ปล่อยมุก มุกภาพ มุกจากความรู้ที่ไม่เท่ากัน |
| การจัดฉากตลกหลายตัวละคร | ห่วงโซ่ปฏิกิริยาในฉากกลุ่ม องค์ประกอบภาพจากการปะทะของตัวละคร มุมมองผู้สังเกตการณ์ |
| บทพูดและจังหวะ | จังหวะบทพูด จังหวะเวลาการแซว ความตลกจากความเงียบ พลังของการซ้ำ |
| การออกแบบการเปลี่ยนฉาก | ตัดสลับแบบเปรียบเทียบความไร้สาระ/ตัดฉับมุกตลก/มอนทาจแบบขัดแย้ง/การเปลี่ยนฉากแบบเสแสร้งจริงจัง |

## วิธีใช้งาน

ชุดทักษะนี้ทำหน้าที่เป็นชุดเทคนิคเล่าเรื่องอ้างอิงสำหรับ AI ผู้กำกับของ ToonFlow โดยจะถูกโหลดโดยอัตโนมัติในกระบวนการสร้างเรื่องราว เพื่อชี้แนะ:

1. **การวางแผนเล่าเรื่อง** — กำหนดแก่นของความตลก เส้นโค้งจังหวะมุกตลก อารมณ์ขันของฉาก และจังหวะเวลาเอฟเฟกต์เสียง
2. **การสร้างตารางสตอรี่บอร์ด** — สร้างแผนขนาดช็อต การเคลื่อนกล้อง ความยาว และการเปลี่ยนฉากที่เป็นรูปธรรม โดยอิงจากแผนการเล่าเรื่อง

ไฟล์ทั้งสองแบ่งหน้าที่กันอย่างชัดเจนและต่อยอดกันเป็นลำดับชั้น ตั้งแต่ "ทำไมต้องถ่ายแบบนี้" ไปจนถึง "ถ่ายอย่างไรโดยเฉพาะ" ก่อให้เกิดวงจรที่สมบูรณ์
